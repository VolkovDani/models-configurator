# Подготовка новой модели Qwen для NPU

[English version](npu-model.md) · [Настройка runtime](npu.ru.md)

Инструкция предназначена для новой установки на Linux x86_64. Если уже есть проверенные локальные файлы OpenVINO IR и соответствующий манифест, переходите к настройке runtime. Для подготовки нужны Python 3.11+ на хосте, Docker Engine, около 40–50 ГБ свободного места на диске и около 19 ГиБ доступной памяти для экспорта. Перед экспортом остановите другие задачи с высоким потреблением памяти.

## Загрузка исходной модели и экспортёра

Из репозитория Models Configurator загрузите общедоступные исходные файлы под лицензией Apache-2.0 в отдельный закрытый каталог. Команда отправляет анонимные HTTPS-запросы за двенадцатью файлами из закреплённого коммита, включая четыре части Safetensors (суммарно 15,23 ГБ весов). SHA256 каждого файла сверяется с ожидаемым. При прерывании повторите команду: она использует уже загруженные и проверенные части. Если существующий файл не совпадает с ожидаемым, команда сохранит его и сообщит об ошибке. [Исходный снимок](https://huggingface.co/Qwen/Qwen2.5-7B-Instruct/tree/a09a35458c702b33eeacc393d103063234e8bc28)

```bash
mkdir -p .npu logs/npu
python3 runtime/npu/prepare_qwen.py download "$PWD/.npu/qwen-source"
docker build -f runtime/npu/Dockerfile.export -t models-configurator-qwen-export:2.2.0 runtime/npu
```

При сборке загружается отдельное окружение экспорта для CPython 3.12 и CPU. Проверяются нативный оператор torchvision и импорт Optimum Intel. Версии зависимостей взяты из окружения, прошедшего аппаратную проверку 17.11.2026. Установщик сначала обновляет pip до 26.3 из официального пакета с закреплённым хешем. Для CPU-сборок Torch и torchvision также закреплены хеши разработчика. На 23.11.2026 в сведениях PyPI об уязвимостях для 60 закреплённых пакетов указаны два предупреждения для Transformers 5.5.4. Optimum Intel 2.2.0 требует Transformers ниже 5.6. Используйте этот набор только в изолированном контейнере без сети и с проверенным источником, как показано ниже. [Проверенный набор зависимостей](https://github.com/VolkovDani/project-creator/blob/4efe6c8/docs/dependency-updates.ru.md) · [Уязвимость путей токенизатора](https://github.com/advisories/GHSA-xrqw-3rrv-vx5w) · [Уязвимость загрузки кода генерации](https://github.com/advisories/GHSA-x9r9-c232-4q39)

## Экспорт без сети

Выполните команды от обычного пользователя Linux. Выберите каталог на диске: только промежуточные файлы могут занять более 15 ГБ. Корневая файловая система контейнера и исходная модель доступны только для чтения. Контейнер работает без сети и учётных данных, сохраняет результат и временные файлы модели в отдельном каталоге. Команде нужен предварительно собранный локальный образ. Перед вызовом экспортёра повторно проверяются хеши всех исходных файлов; лишние файлы и символьные ссылки приводят к ошибке.

```bash
mkdir -p .npu/exports
set -o pipefail
docker run --rm --pull never --network none --read-only --cap-drop ALL \
  --security-opt no-new-privileges --tmpfs /tmp \
  --user "$(id -u):$(id -g)" \
  --mount "type=bind,source=$PWD/.npu/qwen-source,target=/source,readonly" \
  --mount "type=bind,source=$PWD/.npu/exports,target=/out" \
  models-configurator-qwen-export:2.2.0 2>&1 | tee logs/npu/qwen-export.log
```

Используется симметричная поканальная квантизация INT4 с ratio 1.0, размером группы -1 и задачей `text-generation-with-past`. После завершения в `.npu/exports/qwen/` находятся `model/` (IR, токенизатор, лицензия, версии пакетов экспортёра), `profile.json` (хеши всех локальных файлов, ревизия источника, параметры экспорта, версии runtime, лимиты 2048 входных и 512 выходных токенов) и `profile.sha256`. Профиль идентифицирует конкретный результат экспорта. Перед загрузкой runtime проверяет закреплённый профиль и хеши файлов. Существующий каталог `qwen/` сохраняется. После ошибки проверьте журнал, выберите новый пустой родительский каталог для результата и повторите экспорт.

Для запуска runtime в контейнере явно укажите подготовленные файлы:

```bash
export MODELS_NPU_MODEL_DIR="$PWD/.npu/exports/qwen/model"
export MODELS_NPU_MANIFEST="$PWD/.npu/exports/qwen/profile.json"
export MODELS_NPU_PROFILE="$(cat .npu/exports/qwen/profile.sha256)"
```

Все двенадцать закреплённых файлов сверены с метаданными исходного снимка и полными локальными копиями. Детерминированные тесты на малых образцах проверяют загрузку и хеши, параметры автономного экспорта, создание манифеста и сохранность существующих файлов. Реальный экспорт 7B с этими параметрами и зависимостями прошёл аппаратную проверку в Project Creator 17.11.2026. Для нового образа экспортёра менеджера отдельно проверены совместимость установленных зависимостей и нативные импорты. Второй полный экспорт при переносе не проводился.
